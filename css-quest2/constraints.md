# Constraints

- Initially this is just a mechanics demo - no polish styles needed (colours, rounded corners etc) - in fact clear, ugly borders etc for marking boundaries are actually useful right now.
- This is a pure HTML/CSS proof of concept. Feel free to point out where we're hitting the limit and JS would be required, but never suggest JS implementations - it's just not in scope.
- Intended demo platform - mobile safari (iphone). Compatibility with mobile android also desired (but I expect this will be the case with whatever we build since Chromium is always ahead of Safari)
